## Deviations

- Legacy cleanup candidates migrate as `flag` proposals with `payload.suggestedKind` (`merge` or `trash`), not as executable `merge`/`remove` actions: legacy rows have no entry snapshots, and applying an action validates snapshots and versions, so a SQL-only migration cannot build one. The next curation run re-proposes executable actions.
- `reason` is exposed on queue items only when non-empty (additive; keeps the Round 9 pinned test untouched).
- The component test lives in `packages/tests/src/ui/` (the only place the UI vitest config runs), not next to the component.
- Waves 1 and 2 ran in-session after Codex returned `no_quota` (user approved Claude execution).
